# Calculadora de Consumo de Energia

## Objetivo
Criar um programa que calcula o consumo mensal de um aparelho e seu custo aproximado.

## Linguagem
Python.

## Fórmula
Consumo = (potência × horas de uso × 30) / 1000

Para calcular o custo:

Custo = consumo × valor do kWh

O valor usado no projeto é R$ 0,75 por kWh.

## Como executar
1. Abra o arquivo `consumo.py`.
2. Execute o programa com Python.
3. Digite os dados pedidos.
4. O programa mostrará o consumo e o custo mensal.
